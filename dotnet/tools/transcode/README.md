# tools/transcode

Placeholder. This directory holds the **Lua → JSON → MessagePack data transcoder**
delivered by migration ticket 03 ([issue #4](https://github.com/zneel/PathOfBuilding/issues/4)).

## Why it lives here and not in a C# project

`src/TreeData/` (4.1M lines) and the 93.8% of `src/Data/` marked
`-- This file is automatically generated, do not edit!` are Lua *table literals*, not
data files. The only thing that can read them faithfully is a Lua interpreter. The
transcoder therefore runs **on the Lua side**: it loads the existing tables in the
repository's own runtime, walks them, and emits JSON, which a build step then packs to
MessagePack for `Pob.Data` to load at runtime (ticket 18).

Keeping it out of `PathOfBuilding.sln` is deliberate — it is a build-time tool with a
Lua toolchain, not a shipped assembly, and nothing in the solution should take a
dependency on it.

## What ticket 03 will add here

- the Lua dumper that serialises the `src/Data` and `src/TreeData` tables to JSON;
- the packing step to MessagePack;
- a manifest recording source file hashes, so a stale pack is detectable;
- the key contract from ticket 04 ([issue #5](https://github.com/zneel/PathOfBuilding/issues/5))
  for behaviour functions that cannot be transcoded and must be hand-ported.

Until then this file is the only content, so the directory survives in git.
