; Banned APIs for the engine projects (Pob.Core, Pob.Calc, Pob.Parsing) -- see
; docs/migration/tickets/02-luacompat-numerics.md. Applied by
; Microsoft.CodeAnalysis.BannedApiAnalyzers (RS0030); wired up in Directory.Build.props,
; which deliberately does NOT hand this file to Pob.Rendering, Pob.App, Pob.Platform or
; any test project -- geometry and layout code uses Math.Floor legitimately.
;
; Format: <DocumentationCommentId>;<message>
;
; The engine's arithmetic has to match Lua's bit for bit. Math.Round is banker's rounding
; by default and Lua's round() is half-up toward positive infinity, so the two disagree on
; every exact half; Math.Floor/Ceiling/Truncate are fine in isolation but the call sites
; that need them in this engine also need an epsilon or a modf sign rule that is easy to
; drop. Route everything through Pob.Core.LuaCompat, which is pinned to a corpus dumped
; from the real interpreter.
